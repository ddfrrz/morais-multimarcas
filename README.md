# Morais Multimarcas — landing page demo

Código estático da demonstração da landing page da Morais Multimarcas.

**Demo publicada:** https://morais-multimarcas.doubleletterd.chatgpt.site

## Abrir localmente

Execute um servidor estático na raiz do repositório, por exemplo:

```bash
python -m http.server 8000
```

Depois abra http://localhost:8000. O arquivo `index.html` carrega `style.css`, `app.js` e os arquivos em `assets/`.

## Estrutura

- `index.html`: conteúdo e links da página
- `style.css`: visual responsivo e animações
- `app.js`: menu móvel, efeitos e carrossel
- `assets/`: imagens, logo e fontes

Esta versão é uma demonstração institucional. Os botões direcionam ao Instagram e ao Linktree da loja; não há checkout, catálogo dinâmico, formulário ou integração de pagamentos. O endereço da demo é uma publicação separada: mudanças neste repositório não atualizam esse endereço automaticamente.
